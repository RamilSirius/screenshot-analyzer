# 🍎 SystemApp для macOS

Адаптированная версия "Секретного помощника" для macOS с поддержкой GPT-4 Vision анализа скриншотов.

## ✨ Возможности

- 📸 Делает скриншот экрана по горячей клавише
- 🤖 Анализирует скриншот через GPT-4 Vision (OpenAI)
- 🔒 Показывает ответ в скрытом окне (не попадает в запись экрана)
- ⚡ Быстрая обработка через фоновые потоки
- 🖥️ Кроссплатформная поддержка (macOS, Windows, Linux)

## 📋 Требования

- **macOS** 10.13+
- **Python** 3.8+
- **PyQt6** (устанавливается автоматически)
- **OpenAI API ключ** (или Google Gemini)

## 🚀 Быстрый старт

### 1️⃣ Установка зависимостей

```bash
# Перейдите в папку проекта
cd "Telegram Desktop/system app"

# Установите зависимости
pip install -r requirements.txt
```

### 2️⃣ Настройка API ключа

Создайте файл `.env` в папке проекта:

```bash
# Вариант 1: OpenAI
OPENAI_API_KEY=sk-your-key-here

# Вариант 2: Google Gemini (в файле server_gemini.py)
GEMINI_API_KEY=your-key-here

# Опционально: адрес сервера (по умолчанию localhost:8000)
SERVER_URL=http://localhost:8000
```

**Где получить ключ:**
- OpenAI: https://platform.openai.com/api-keys
- Gemini: https://aistudio.google.com/app/apikey

### 3️⃣ Запуск сервера

В отдельном терминале запустите сервер:

```bash
python3 server.py
```

Или с Gemini:
```bash
python3 server_gemini.py
```

Вы должны увидеть:
```
==================================================
🚀 Сервер запускается на http://localhost:8000
📡 Endpoint для анализа: POST /analyze
==================================================
```

### 4️⃣ Запуск клиента

В главном терминале запустите клиент:

```bash
python3 client_fixed.py
```

Вы должны увидеть:
```
==================================================
🔒 Секретный помощник запущен! (macOS)
==================================================

📡 Сервер: http://localhost:8000

📌 Управление:
   Shift+A   → Сделать скриншот и получить ответ
   Shift+D   → Показать/скрыть окно с ответом
   F + '\' → Закрыть приложение полностью
   ...
```

## ⚙️ Разрешение Input Monitoring на macOS

Для работы глобальных горячих клавиш на macOS нужно разрешить "Input Monitoring":

### Способ 1: Автоматический (рекомендуется)

При первом запуске приложение может запросить разрешение. Нажмите **Allow** (Разрешить).

### Способ 2: Вручную

1. Откройте **System Preferences** (или **System Settings** на macOS 13+)
2. Перейдите в **Security & Privacy** → **Input Monitoring**
3. Нажмите 🔒 (замок внизу слева) и введите пароль
4. Найдите **Python** в списке и убедитесь, что он включен
5. Закройте и перезагрузитесь

## 🔧 Troubleshooting

### Проблема: "Keyboard listener умер"

**Решение:** Переоткройте System Preferences и убедитесь, что Python имеет разрешение на Input Monitoring.

### Проблема: "Сервер недоступен"

**Решение:** 
- Убедитесь, что сервер запущен в отдельном терминале
- Проверьте, что SERVER_URL в .env указан правильно
- Если используете удалённый сервер, убедитесь в интернет-соединении

### Проблема: "Окно не показывается"

**Решение:** Нажмите **Shift+D** чтобы показать окно, или проверьте логи в терминале.

### Проблема: PyQt6 не устанавливается

**Решение:**
```bash
python3 -m pip install --upgrade pip
python3 -m pip install PyQt6 --force-reinstall
```

### Проблема: ImageGrab не работает

На macOS используется встроенная функция для скриншотов. Если она не работает:

```bash
python3 -m pip install --upgrade Pillow
```

## 🌐 Использование удалённого сервера

Если вы хотите использовать удалённый сервер вместо локального:

1. Измените `.env`:
```bash
SERVER_URL=https://your-server.com
```

2. Убедитесь, что сервер доступен и имеет необходимые разрешения CORS

## 🔐 Безопасность

⚠️ **Важно:**
- Не делитесь своим API ключом
- Скриншоты отправляются на серверы OpenAI/Google
- Окно с ответом скрыто от записи экрана только на Windows
- На macOS/Linux это не гарантируется технически
