ОПИСАНИЕ:
---------
Приложение делает скриншот экрана по хоткею и анализирует его
через OpenAI GPT-4 Vision. Ответ показывается в окне,
скрытом от записи экрана.


УСТАНОВКА:
----------
1. Установи зависимости:
   pip install -r requirements.txt

2. Создай файл .env в папке проекта с содержимым:
   OPENAI_API_KEY=sk-твой-ключ-openai

3. Получить API ключ можно тут: https://platform.openai.com/api-keys


ЗАПУСК:
-------
1. Сначала запусти СЕРВЕР (в отдельном терминале):
   python server.py

2. Затем запусти КЛИЕНТ:
   python client.py


УПРАВЛЕНИЕ:
-----------
• F + "-"  → Сделать скриншот и получить ответ от AI
• ESC      → Скрыть окно с ответом  
• ПКМ      → Скрыть окно с ответом


СБОРКА .EXE:
------------
Запусти build.bat или выполни:
   pyinstaller --onefile --windowed --name SecretHelper client.py

Готовый файл будет в папке dist/


ВАЖНО:
------
• Окно с ответом СКРЫТО от записи экрана (Windows 10+)
• Сервер должен быть запущен для работы клиента
• Для продакшна рекомендуется захостить сервер удалённо


СТРУКТУРА ПРОЕКТА:
------------------
├── client.py      - Клиент (хоткеи + скриншоты)
├── server.py      - Сервер (FastAPI + OpenAI)
├── requirements.txt
├── build.bat      - Скрипт сборки .exe
└── .env           - API ключ (создай сам!)
